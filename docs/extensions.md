# Extensions

An extension is a small add-on that connects the app to one website. Install one extension per
site you want to read or watch from.

## Install your first extension

1. Open the app and go to **Extensions** in the bottom bar (on desktop, the Home tab).
2. Tap **Get extensions**.
3. Browse the catalog, pick a source, and tap **Install**.
4. If the extension shows **untrusted**, tap **Trust**. Only trust extensions from repos you
   chose to add.
5. Go to **Recent** or **All**. Content from that source shows up there.

## Adding a repo (a list of extensions)

Community extension lists are called *repos*. To add one:

1. Go to **Extensions** › **⋮** menu › **Custom repos**.
2. Paste the repo link into **Custom Url** and add it.
3. Its extensions appear under **Get extensions**.

OtakuWorld doesn't host or recommend any third-party repo. Find them through each project's own
community.

## Extension types

| Type                          | Works in       | Android | Desktop | What you install          |
|-------------------------------|----------------|---------|---------|---------------------------|
| **OtakuWorld catalog**        | All apps       | ✅       | ✅       | Built into the app        |
| **Mihon / Tachiyomi**         | MangaWorld     | ✅       | ✅ ¹     | Extension APK from a repo |
| **Aniyomi**                   | AnimeWorld     | ✅       | ✅ ¹     | Extension APK from a repo |
| **CloudStream**               | AnimeWorld     | ✅       | ✅ ¹     | `.cs3` plugin from a repo |
| **JavaScript / TypeScript**   | All apps       | ✅       | ✅       | `.js` or `.ts` file       |

¹ On desktop, sources that need a Cloudflare check, an Android web view, or their own settings
screen don't work yet. The app converts Android extensions for desktop by itself; you don't need
to do anything.

On Android, extension APKs install like any other app, so you may see an install prompt for each
one. That's normal.
