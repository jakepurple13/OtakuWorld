# On-device AI

Some features use a small AI model that runs on your own device: TL;DR summaries, note writing
tools, mood suggestions, update summaries, and novel chapter recaps. Nothing is sent to a cloud
service.

- **Android:** uses Gemini Nano on phones that have it (such as recent Pixels). Otherwise you can
  import a model file in **Settings › Integrations › AI**.
- **Desktop:** import a model file, or install Ollama.

If no AI is set up, the AI buttons simply don't appear. You can turn every AI feature off in
**Settings › Integrations › AI**.

To get a model file, see [Use a small AI model](small-model.md).
