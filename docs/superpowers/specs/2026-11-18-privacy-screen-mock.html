Compose mapping

  • Rows: existing CategoryGroupListItem { segmentedListItem(…) } with trailingContent = { Switch(…) } and supportingContent for the subtitle.
  • Group label: same style as other settings section headers.
  • Crash hint: AnimatedVisibility(expandVertically() + fadeIn()) under the group, shown when the crash switch is off.
  • Option B slide: Navigation3 default push transition.
  • Visibility: group renders only when koinInject<CrashReporter>().isAvailable, which is false for the no-op implementations.
  • Settings search: register both toggles in SettingsSearchRegistry so "analytics" and "crash" find them.
