# Mood Tags Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lazily AI-tagged moods for favorites: shown on Details, filterable on Favorites, and summarized in account stats.

**Spec:** `docs/superpowers/specs/2026-11-17-mood-tags-design.md`

## Global Constraints

- No background or bulk tagging. Tag only from an open Details screen.
- Never touch Supabase sync or `DbModel`.
- Use `aiText.availability` so the feature follows the AI page live.
- Commit the exported Room schema `favoritesdatabase/schemas/com.programmersbox.favoritesdatabase.ItemDatabase/12.json`.
- Tests: `./gradlew :favoritesdatabase:jvmTest :kmpuiviews:jvmTest`. Build: `./gradlew :mangaworld:assembleNoFirebaseDebug`.

## Review Focus

1. Opening the same untagged favorite twice in a session tags it once, and an empty result is never retried. Pinned by `tags once and never retries an empty result`.
2. Non-favorites are never tagged. Pinned by `non favorites are not tagged`.
3. The v11→v12 migration keeps existing data. Pinned by `migration 11 to 12 adds mood_tags and keeps favorites`.
4. AI output outside the mood list is dropped. Pinned by `mood finish keeps only known moods`.
5. The filter only counts favorites (not unfavorited rows). Pinned by `favoriteMoodTags only returns favorites`.

### Task 3: MoodTagger
**Files:** `domain/moodtags/MoodTagger.kt` (Koin single), `MoodTaggerTest`.

**Interfaces:**
```kotlin
class MoodTagger(aiText: AiText, dao: ItemDao) {
    fun moods(url: String): Flow<List<Mood>?>            // null = not tagged yet
    val favoriteMoods: Flow<Map<String, List<Mood>>>     // url → moods, favorites only
    /** Tags [url] once if it has no row; returns quietly when no engine or no description. */
    suspend fun tagIfNeeded(url: String, title: String, description: String)
    suspend fun remove(url: String, mood: Mood)
    val enabled: Flow<Boolean>                           // availability(MoodTags) != null
}
```
