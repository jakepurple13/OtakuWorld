# Mood Tags Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Moods on favorites: hand-picked, custom, or AI-suggested on tap. Shown on Details, filterable on Favorites, summarized in stats.

**Spec:** `docs/superpowers/specs/2026-11-17-mood-tags-design.md`

## Global Constraints

- Nothing generates on its own. AI runs only from the Suggest chip.
- The AI switch gates only the Suggest chip.
- Never touch Supabase sync or `DbModel`. Commit the exported schema `favoritesdatabase/schemas/com.programmersbox.favoritesdatabase.ItemDatabase/12.json`.
- Tests: `./gradlew :favoritesdatabase:jvmTest :kmpuiviews:jvmTest`. Build: `./gradlew :mangaworld:assembleNoFirebaseDebug`.

## Review Focus

1. The v11→v12 migration keeps existing data. Pinned by `migration 11 to 12 adds mood_tags and keeps favorites`.
2. AI suggestions outside the allowed moods are dropped, with at most 3. Pinned by `suggest keeps only allowed moods`.
3. Removing the last mood deletes the row, so the AI chip returns. Pinned by `empty moods delete the row`.
4. Stats and the filter count only favorites. Pinned by `favoriteMoods only returns favorites`.
5. Custom names are deduped case-insensitively and capped. Pinned by `custom names are cleaned and deduped`.

### Task 1: Table, DAO, migration
`MoodTagRow`, `ItemDao` (`moodsFlow(url)`, `upsertMoods`, `deleteMoods(url)`, `favoriteMoodRows()`, `allMoodRows()`), `ItemDatabase` v12 + `MIGRATION_11_12`, schema json. Tests: `MoodTagsDaoTest` and `ItemDatabaseMigration11To12Test`.

### Task 2: Mood catalog and AI feature
`domain/moodtags/Moods.kt` (`BuiltInMoods` ids + `StringResource` labels, `cleanCustomMood`), `AiFeature.MoodTags`/`MoodInput`, `AiToggle.MoodTags`, AI page Library row, strings. Tests in `MoodsTest`, `AiFeatureTest` and `AiSettingsTest`.

### Task 3: MoodRepository
`moods(url): Flow<List<String>>`, `favoriteMoods: Flow<Map<String, List<String>>>`, `customMoods: Flow<List<String>>`, `toggle(url, mood)`, `remove(url, mood)`, `create(url, name): Boolean`, `suspend fun suggest(url, title, description): Boolean`. Koin single. Test `MoodRepositoryTest`: `empty moods delete the row`, `suggest keeps only allowed moods`, `custom names are cleaned and deduped`, `custom moods disappear when unused`, `suggest without engine returns false`.

### Task 4: Details
`DetailsViewModel` exposes `moods`, `customMoods`, `canSuggestMoods` (favorite + no moods + `availability(MoodTags)`), `suggestingMoods`, `suggestMoods()`, `toggleMood`, `removeMood` and `createMood`. UI: a Mood row under the genres for favorites, the AI chip with `Spark` + `generatingBorder`, the ＋ Add `ModalBottomSheet` with a create field, and long-press remove. VM tests.

### Task 5: Favorites filter
`FavoriteViewModel`: `selectedMoods`, `moodCounts`, `untaggedCount`, mood filtering, and moods counted in `activeFilterCount` and reset. `FavoritesFilterSheet` Mood section + note. VM tests.

### Task 6: Account stats
`MoodStatisticsProvider` (hidden when nothing is tagged) + binding. Test.
