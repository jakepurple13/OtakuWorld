# Navigation Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Debug/noFirebase-only "Navigation map" screen showing every registered screen and every code path that navigates to it, per app.

**Architecture:** A plain-JVM `:navgraph` tool scans Kotlin sources with regex + brace matching, merges hand-written overrides, and writes `navgraph.json`. A buildSrc task runs it and adds the output to Android assets for debug and noFirebase variants. `kmpuiviews` loads the JSON, lays it out by BFS depth, and renders a Map (canvas) and Focus (lists) UI.

**Tech Stack:** Kotlin JVM, kotlinx.serialization, Gradle (buildSrc, AGP Variant API), Compose Multiplatform, Koin navigation3.

**Spec:** `docs/superpowers/specs/2026-11-12-nav-map-design.md`

## Global Constraints

- Generated asset ships only when `buildType == "debug"` or flavor is `noFirebase`. Never in `fullRelease`/`fullBeta`.
- Navigation map row visible only when `appConfig.isDebug || appConfig.buildType == BuildType.NoFirebase`.
- Asset file name: `navgraph.json` at assets root.
- Node id = key's qualified name inside its package with a leading `Screen.` removed (`DetailsScreen.Details`, `ReadViewModel.MangaReader`, `Settings.Appearance`). Pseudo ids start with `@`.
- Target/reference resolution: exact id match, else the unique node whose id ends with `.<text>`; otherwise unresolved.
- Colors: inbound teal, outbound amber, orphans red ring, overrides dashed — from `MaterialTheme.colorScheme` (tertiary = inbound, primary = outbound, error = orphan).
- Every lazy item uses `Modifier.animateItem()` (project rule).
- CI runs `./gradlew jvmTest testAndroidHostTest`; `:navgraph` must alias `jvmTest` → `test`.

## Review Focus

1. A `navigate(...)` whose argument is an expression (`item.videoScreen()`, `route`) → goes to `unresolved` with reason `dynamic target`, never crashes or fabricates an edge. (Task 2 test)
2. Comments and string literals containing `navigate(Screen.X)` or braces → ignored, brace matching unaffected. (Task 1 test)
3. Two keys with the same simple name (`NotesScreen.Detail`, `DictionaryScreen.Detail`) → a bare `Detail` reference is ambiguous → unresolved, not an arbitrary pick. (Task 3 test)
4. Asset missing (fullRelease, desktop) → screen shows empty state, no crash. (Task 7 test)
5. "Open" on a key whose constructor takes an unsupported type (e.g. a nested data class) → returns null, button disabled, no crash. (Task 6 test)

### Task 3: Overrides, graph builder, JSON, CLI

**Files:**
- Create: `navgraph/src/main/kotlin/com/programmersbox/navgraph/Overrides.kt`, `GraphBuilder.kt`, `NavGraphJson.kt`, `Main.kt`
- Test: `navgraph/src/test/kotlin/com/programmersbox/navgraph/OverridesTest.kt`, `GraphBuilderTest.kt`

**Interfaces — Consumes:** Tasks 1–2. **Produces:**
- JSON model (`@Serializable`, exact field names — Task 6 mirrors them):
  ```kotlin
  data class NavGraphJson(val app: String, val nodes: List<NodeJson>, val edges: List<EdgeJson>, val unresolved: List<UnresolvedJson>)
  data class NodeJson(val id: String, val label: String, val fqcn: String?, val args: List<Arg>, val pseudo: Boolean, val allowOrphan: Boolean)
  data class SiteJson(val file: String, val line: Int)
  data class EdgeJson(val from: String, val to: String, val origin: String /* "scan" | "override" */, val sites: List<SiteJson>, val note: String?)
  data class UnresolvedJson(val file: String, val line: Int, val text: String, val reason: String)
  ```
- Overrides line format (`#` comments, blank lines ignored; `file` matches by file name):
  ```
  entry @NavBar "Nav bar"
  file HomeNav.kt -> @NavBar
  file OptionsSheet.kt -> RecentScreen, AllScreen
  edge Settings -> GeneralSettings : settings rows in Nav3Graph.kt
  ignore DebugFragment.kt
  allow-orphan ColorHelper
  ```
  `data class Overrides(val entries: Map<String,String>, val fileOwners: Map<String,List<String>>, val edges: List<OverrideEdge>, val ignored: Set<String>, val allowOrphans: Set<String>)`, `data class OverrideEdge(val from: String, val to: String, val note: String?)`, `fun parseOverrides(text: String): Overrides` (throws `IllegalArgumentException("line N: …")` on bad syntax).
- `fun buildGraph(app: String, sources: List<KotlinSource>, overrides: Overrides): NavGraphJson` — throws `IllegalStateException` listing every override id that does not resolve. Nodes = registered keys that resolve to a declaration (+ pseudo entries). Attribution order per call site: `fileOwners` → enclosing registration body → file that declares (`fun Name(`) one of the registration's `composables` (a file claimed by 2+ keys is not mapped) → only mapped file in the same directory → unresolved `no source screen`. Unresolved targets: reason `dynamic target` / `unknown key` / `ambiguous key`. Self-edges dropped. Edges deduped on (from,to); scan sites merged; an override edge equal to a scanned one keeps origin `scan`. Files containing `: NavigationActions` or `interface NavigationActions` and `ignored` files produce no call sites. Output sorted (nodes by id, edges by from/to) so builds are reproducible.
- `fun main(args: Array<String>)` — `--app <name> --root <repoDir> --out <file> --overrides <file>...`; source dirs from `AppSources` (Task 4); writes pretty-free JSON with `Json { encodeDefaults = true }`.
