# Desktop add-ons

You don't need any of these. They unlock extra features.

| Add-on                 | App        | What it does                                                    | Where to set it up                         |
|------------------------|------------|-----------------------------------------------------------------|--------------------------------------------|
| **whisper.cpp**        | AnimeWorld | Writes subtitles for downloaded episodes that don't have any   | Settings › Subtitles (can download it for you) |
| **ffmpeg**             | AnimeWorld | Exports downloaded episodes as normal video files. whisper.cpp needs it too | The Video export screen asks for it if it isn't found |
| **Ollama**             | All apps   | A local AI model for summaries, translations, and the AI features | Settings › Integrations › AI              |
| **Model file** (`.litertlm`) | All apps | A small on-device AI model, such as Gemma 3 1B             | Settings › Integrations › AI › Import model file |

The video player is built in. You don't need to install VLC.
