# Common problems

**The app is empty.** You need to install an extension first. See
[Install your first extension](extensions.md#install-your-first-extension).

**A source shows nothing or an error.** The website may be down or changed. Try another source,
or check **Extensions** for an update. Settings › Update check errors explains common errors.

**I installed the no-firebase version and lost my favorites.** The two versions are separate
apps. Make a backup in **Settings › Backup & Restore** in the old one, then restore it in the new one.

**I can't go back to an older version.** Newer versions upgrade the app's database. To go back,
make a backup, uninstall, install the older version, and restore.

**Still stuck?** Ask on [Discord](https://discord.gg/MhhHMWqryg) or
[open an issue](https://github.com/jakepurple13/OtakuWorld/issues). Include your app, version,
device, and what you tapped.
